# 期货库存数据处理工具 - 使用说明 v4.5

> **当前版本**: v4.5 | **脚本文件**: `期货库存工具_v4.py` | **更新日期**: 2026-05-08

---

## 📋 功能概述

本工具自动化处理期货库存数据，每次运行执行以下流程：

| 步骤 | 功能 | 说明 |
|------|------|------|
| 0 | **备份原文件** | 程序启动前自动备份 `期货库存明细.xlsx` → `期货库存明细_备份.xlsx`（覆盖模式） |
| 1 | 读取表头模板 | 优先使用 Sheet2，无则使用第一个客户 Sheet 的表头 |
| 2 | 读取期货排程 | 提取订单号、客户名称、合同日期 |
| 3 | 读取烨辉库存表 | 建立钢卷号 → 仓别/移拨日期/入库日期 映射 |
| 3.5 | 读取原文件数据 | 加载所有客户 Sheet 中的现有钢卷数据 |
| 3.6 | 构建索引 | 以钢卷号为 key 建立快速查找映射 |
| 4 | 差异比对 | 以期货排程订单为基准，识别新增/更新/保留 |
| 5 | 重建 Sheet | 按客户分组，写入所有数据 |
| 6 | 保存文件 | 直接覆盖更新 `results/期货库存明细.xlsx` |

---

## 🔑 核心逻辑

### 处理规则（以钢卷号为唯一标识）

```
每次运行时：
┌─ 原文件已有的钢卷
│   ├─ 烨辉表中存在 + 仓别【有变动】  → 更新仓别/移拨日期/入库日期 🟠 橙色
│   ├─ 烨辉表中存在 + 仓别【无变动】  → 原样保留（无颜色）
│   └─ 烨辉表中【不存在】            → 原样保留（不删减）
│
└─ 原文件没有的钢卷
    ├─ 期货排程有订单 + 烨辉表有数据   → 新增 🟡 黄色（标注修改日期）
    └─ 非期货排程订单                  → 跳过（不引入无关数据）
```

> **只增加不删减**：原文件中已有的钢卷，不论烨辉表是否存在，永远不会被删除。

## 🎨 颜色标注说明

| 颜色 | 含义 | 触发条件 |
|------|------|----------|
| 🟠 **橙色** `#FFA500` | 仓别已更新 | 该钢卷的倉別在烨辉表中与原文件不一致 |
| 🟡 **黄色** `#FFFF00` | 新增钢卷 | 钢卷号不在原文件中，从烨辉表首次导入 |
| ⬜ **无色** | 原数据保留 | 仓别无变化，或烨辉表中不存在（保留） |

## 🔄 仓别更新逻辑详解

```python
# Step 4.1 核心判断
for row_info in original_all_rows:
    coil_no       = row_info['coil_no']       # 原文件 Col 4
    old_warehouse = row_info['warehouse']      # 原文件 Col 12

    if coil_no in yehui_coil_info:
        new_warehouse = yehui_coil_info[coil_no]['warehouse']  # 烨辉表 Col 32

        if old_warehouse != new_warehouse:     # 对比：字符串精确比较
            → updated (橙色)：更新 倉別 + 移撥日期 + 入庫日期
        else:
            → preserved (保留)
    else:
        → preserved (保留，不删减)
```

**更新时写入内容：**
- `倉別`    ← 烨辉表 Col 32（新仓别）
- `移撥日期` ← 烨辉表 Col 33（格式化为 YYYY/M/D）
- `入庫日期` ← 烨辉表 Col 29（格式化为 YYYY/M/D）
- 其余列    ← 保留原文件数据不变

            → new (黄色)：新增该钢卷

**新增时写入内容：**
- `合同日期`  ← 期货排程 Col 1
- `客户名称`  ← 期货排程 Col 2
- `訂單編號`  ← 期货排程 Col 3
- `鋼捲編號`  ← 烨辉表 Col 8
- `倉別`      ← 烨辉表 Col 32
- `移撥日期`  ← 烨辉表 Col 33
- `入庫日期`  ← 烨辉表 Col 29

## ⚠️ 注意事项

| 注意点 | 说明 |
|--------|------|
| 文件占用 | 运行前请关闭 Excel，否则保存失败 |
| 临时文件 | `~$*.xlsx` 自动跳过 |
| 备份文件 | 文件名含「备份」的自动跳过；程序自动创建「期货库存明细_备份.xlsx」 |
| 备份模式 | 覆盖模式，只保留一份最新备份，重复运行会覆盖旧备份 |
| Sheet名限制 | 最长 31 字符，特殊字符自动替换为 `_` |
| 仓别比较 | 精确字符串比较，注意全/半角、空格差异 |
| 钢卷号去重 | 以钢卷号为唯一 key，同一钢卷不会重复添加 |
